# 📢 InkNest v1.5.1 Release Announcement

Hey everyone! 🎉 We're excited to announce **InkNest v1.5.1** is now available!

This release modernizes InkNest on **React Native 0.84.1**, restores reliable access to **Read Comics Online**, removes AdMob advertising, and delivers important loading, navigation, and platform stability improvements.

<!-- truncate -->

## ✨ What's New

### 📚 Read Comics Online Is Back

- **Updated for the latest site design** — Home, comic details, chapters, and search have been refreshed for the 2026 Read Comics Online layout
- **Cloudflare verification support** — InkNest can now guide you through verification when a protected page cannot be opened automatically
- **Persistent verified sessions** — Clearance cookies and the matching browser identity are saved so browsing, covers, and reader images continue working after verification
- **More complete search results** — Advanced search replaces the limited autocomplete flow and returns a wider selection from the catalog
- **Clearer library states** — New loading, verification, failure, and retry states make protected-source issues easier to understand and recover from

### 🚫 Ad-Free App Experience

- Removed AdMob banner and rewarded-ad integrations from browsing and reading flows
- Removed injected ad cards from content lists
- Downloads and source navigation no longer trigger rewarded-ad prompts

### 🌐 New InkNest Website and Documentation

- Added a new documentation website with feature highlights, platform downloads, support links, and contribution information
- Added an interactive FAQ covering installation, reading features, troubleshooting, and project contributions
- Published a release archive so you can easily review what changed in earlier InkNest versions

## 🔧 Improvements

### Faster, More Reliable Loading

- Replaced the native loading modal with a lightweight overlay to prevent frozen navigation and blocked back-button behavior
- Added a **30-second request timeout** so stalled network calls no longer leave screens loading indefinitely
- Fixed chapter selection so the complete filtered chapter list is available outside the Recent tab

### Source and Navigation Cleanup

- Removed the no-longer-supported **ComicHubFree** integration from Home, Search, Details, and Reader flows
- Made **Read Comics Online** the default comic source and standardized its home section as **Latest Release**
- Simplified the bottom navigation by removing the Community tab and cleaned up the Settings shortcuts
- Improved participant profile queries by updating the Firestore integration to its supported modular API

### Platform and Storage Updates

- Rebuilt InkNest on **React Native 0.84.1** for a more modern Android and iOS foundation
- Fixed vector icon font loading on iOS and bundled the required icon assets on Android
- Moved Manga gravity-scroll preferences and walkthrough state to **MMKV** for faster, more reliable persistence
- Enabled Android crash reporting and refreshed native dependencies for improved compatibility

## 📱 Release Details

- **Android:** Version 1.5.1 (build 40)
- **iOS:** Version 1.5.1

**Update now** to enjoy more reliable comic browsing, a cleaner ad-free experience, and a stronger foundation for future InkNest updates! 📚✨

As always, if you encounter any issues, please report them through our support channels. Happy reading! 🦋
